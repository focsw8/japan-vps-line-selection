## 日本 VPS 推荐先定三件事：线路、IP、带宽和流量

### 线路名字对应不同的走向

早几年日本 VPS 只有「软银直连」和「国际线路」两种说法，现在拆得细了：IIJ、NTT、BGP 三网优化、CN2 回程。同一台机器，线路选错，50ms 的机房也能跑出 200ms 的体感。

软银直连是电信、联通、移动三网去程回程都走 SoftBank（bbtec.net）骨干，延迟稳定，晚高峰不太掉速，目前算性价比最高的一档准优质线路。CN2 GIA 是电信走 CN2 GIA、联通移动走 CMI 或普通线路，电信用户体验最好，但只有电信吃到这波红利，联通移动付了钱享受不到。IIJ 是日本第二大 ISP，三网质量稳定，比软银稍逊，价格更低。再往下是 CMI 这类移动优化线路，以及最便宜也最容易卡的普通国际带宽。

还有一类要单独拎出来说：绕路货。去程绕美西、回程绕香港或者干脆绕欧洲，延迟直接飙到 200ms 以上，晚高峰丢包严重。这种机房再便宜也别买，买回来每天都在跟它较劲。

### 延迟的真实区间是 50 到 110ms

东京、大阪到国内骨干网，延迟基本落在 50–110ms，美西机房至少 150ms 起步。一份针对大阪软银线路的第三方测评给过更细的分城市数据：上海联通约 45–55ms，上海电信 50–60ms，广东电信 60–70ms，上海移动 60–70ms，广东移动 70–80ms，广东联通会到 100–110ms。三网均值 100ms 出头，电信表现最好，移动晚高峰会有点抖，但基本不丢包。

这组数字说的是软银线路，不是六六云某一台机器的实测。同一条线路上不同商家、不同套餐的实际表现会有出入，只能当参考区间用。

比区间更值得记的是另一句话：不要只看 ping 值。白天 50ms、晚高峰跳到 150ms 的机房，比全天稳定在 80ms 的机房难受得多。下单前把商家的测试 IP 拿到手，自己在晚上八九点 ping 一轮，比看十篇测评都准。

### 原生 IP 决定你能解锁什么

原生 IP 指 IP 段在日本 RIR 注册、由日本 ISP 实际持有。流媒体平台识别的时候，才会把你当成本地用户。广播 IP（非原生）经常被识别成「使用 VPN／代理」，直接挡在门外。

日本原生 IP 能解锁的东西比较实在：Netflix 日区、Disney+ JP、AbemaTV、DMM、TikTok 日本版，以及走日区出口的 ChatGPT。有这些需求，下单前问清楚 IP 是不是日本原生段，或者拿测试 IP 自己查一遍归属。

### 带宽和流量是两回事

带宽是管子粗细，流量是水表。一个写着 1000GB／1Gbps 的套餐，1Gbps 跑满大约是 450GB 每小时，两个多小时就能把整月流量烧光。带宽大不等于能随便跑。

日常建站、SSH、轻量中转，500GB 起步够用；跑流媒体、做下载、几个人共用，至少留 1TB。价格方面，市面上日本 VPS 从每月 2.99 美元到 900 美元一年都有，软银和 IIJ 的常规档集中在 45–200 美元一年，折人民币三百多到一千四。低于这个区间一大截的，多半是绕路货或者超售得厉害。

## 常见问题

### 日本 VPS 和香港 VPS 怎么选？

香港延迟更低，20–30ms，但带宽小、价格贵、原生 IP 资源紧张。日本延迟稍高，换来的是带宽大、流量多、原生 IP 选择丰富。纯做大陆中转，香港更优；业务面向东南亚和日本本地，选日本。

### 软银和 CN2 GIA 到底差在哪？

软银是三网去回程都走 SoftBank 骨干，三家运营商体验均衡，谁都不吃亏。CN2 GIA 是电信走 CN2 GIA、联通移动走 CMI 或普通线路，电信最优，另外两家付了钱没享受到那份优化。你是电信用户就选 CN2 GIA，联通用户选软银更划算。

### 1000GB 流量够不够用？

看干什么。建站、SSH、轻量代理，1000GB 一个月大概率用不完。跑流媒体、做下载、多人共用，1Gbps 端口满速两个多小时就能烧完 1000GB，这种用法直接上 2000GB 档。

### 原生 IP 具体有什么用？

Netflix 日区、Disney+ JP、AbemaTV、DMM、TikTok 日本版，以及走日区出口的 ChatGPT，都要求平台把你识别为日本本地用户。广播 IP 会被判定成代理直接挡掉，原生 IP 才能正常解锁。

### 六六云日本线有优惠码吗？

官方目前没有放出适用于日本线的优惠码，第三方优惠站上流传的那些码没法核实有效期和适用范围，这里不列。想省钱有两个办法：不需要原生 IP 就选 48 元档，一年 576 元；打算长期用，先按季付试一档，确认线路和速度对得上再考虑更长的周期，别一上来就押一年。
